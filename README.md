# BedWars - 起床战争

一个基于Node.js的小型BedWars游戏，仿照我的世界起床战争。支持1v1到4v4的游戏模式，包含资源收集、商店购买、团队指令等功能。

## 🎮 游戏特性

- **多种游戏模式**: 支持1v1到4v4的团队对战
- **资源系统**: 铁锭、金锭、钻石、绿宝石四种资源
- **商店系统**: 可以购买武器、防具、工具、方块和特殊物品
- **AI对手**: 其他玩家由AI控制，支持智能决策
- **团队指令**: 按F键发送团队指令（全员保护床、全员出击、跟我走）
- **重生系统**: 死亡后5秒重生
- **床破坏机制**: 破坏敌方床后无法重生

## 📋 游戏规则

1. **游戏目标**: 破坏敌方的床并消灭所有敌方玩家
2. **资源收集**: 点击地图上的资源进行收集
3. **商店购买**: 按E键打开商店，使用收集的资源购买物品
4. **团队合作**: 使用F键发送团队指令，协调队友行动
5. **重生机制**: 死亡后5秒自动重生，如果床被破坏则无法重生

## 🚀 快速开始

### 先决条件

- Node.js (v14或更高版本)
- npm 或 yarn

### 安装

```bash
# 克隆项目
cd BEDWARS-HTML

# 安装依赖
npm install

# 启动服务器
npm start
```

### 运行游戏

1. 启动服务器后，打开浏览器
2. 访问 `http://localhost:3000`
3. 输入玩家名字，选择队伍（或自动分配）
4. 点击"开始游戏"按钮
5. 等待其他玩家加入或添加AI玩家

## 🎯 控制说明

### 键盘控制

| 按键 | 功能 |
|------|------|
| W / ↑ | 向前移动 |
| S / ↓ | 向后移动 |
| A / ← | 向左移动 |
| D / → | 向右移动 |
| 空格 | 攻击 |
| E | 打开商店 |
| F | 团队指令菜单 |
| ESC | 关闭菜单 |

### 鼠标控制

- **点击资源**: 收集资源
- **点击敌方床**: 破坏床
- **点击商店物品**: 购买物品

## 🤖 AI系统

AI玩家具有以下行为：

1. **资源收集**: 优先收集附近的资源
2. **攻击敌人**: 发现敌人时会主动攻击
3. **保护床**: 当床受到威胁时会回到床边保护
4. **团队合作**: 响应队友的团队指令
5. **购买物品**: 根据资源数量自动购买合适的装备

## 👥 团队指令

| 指令 | 描述 |
|------|------|
| 🛡️ 全员保护床 | 所有AI队友会集中保护床 |
| ⚔️ 全员出击 | 所有AI队友会主动攻击敌人 |
| 👣 跟我走 | 所有AI队友会跟随你移动 |

## 📊 游戏配置

可以在 `server.js` 中修改游戏配置：

```javascript
const GAME_CONFIG = {
  mapSize: { width: 800, height: 600 },      // 地图大小
  teamSizes: [1, 2, 3, 4],                  // 支持的队伍大小
  defaultTeamSize: 2,                       // 默认队伍大小
  respawnTime: 5000,                        // 重生时间（毫秒）
  gameDuration: 300000,                     // 游戏时长（毫秒）
  resourceSpawnInterval: 10000,            // 资源生成间隔（毫秒）
  aiUpdateInterval: 100                    // AI更新间隔（毫秒）
};
```

## 🎨 自定义

### 修改资源生成率

在 `server.js` 中修改 `RESOURCE_TYPES`：

```javascript
const RESOURCE_TYPES = {
  IRON: { name: '铁锭', color: '#A8A8A8', value: 1, spawnRate: 0.6 },
  GOLD: { name: '金锭', color: '#FFD700', value: 3, spawnRate: 0.3 },
  DIAMOND: { name: '钻石', color: '#00BFFF', value: 6, spawnRate: 0.1 },
  EMERALD: { name: '绿宝石', color: '#50C878', value: 10, spawnRate: 0.05 }
};
```

### 添加新物品

在 `server.js` 中修改 `SHOP_ITEMS`：

```javascript
const SHOP_ITEMS = {
  weapons: [
    { id: 'new_sword', name: '新剑', cost: 100, type: 'weapon', damage: 12, tier: 5 }
  ],
  // ... 其他分类
};
```

## 🐛 故障排除

### 服务器无法启动

1. 检查Node.js是否已安装：`node -v`
2. 检查端口是否被占用：`lsof -i :3000`
3. 尝试更换端口：修改 `server.js` 中的 `PORT`

### 无法连接到服务器

1. 检查服务器是否正在运行
2. 检查浏览器是否支持WebSocket
3. 尝试使用不同的浏览器
